The Apache Flink community is excited to announce the release of Flink Kubernetes Operator 1.8.0! The release includes many improvements to the operator core, the autoscaler, and introduces new features like TaskManager memory auto-tuning. We encourage you to download the release and share your experience with the community through the Flink mailing lists or JIRA!
