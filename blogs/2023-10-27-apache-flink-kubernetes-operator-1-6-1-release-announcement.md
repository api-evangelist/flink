The Apache Flink Community is pleased to announce the first bug fix release of the Flink Kubernetes Operator 1.6 series. The release contains fixes for several critical issues, and some doc improvements for the autoscaler. We highly recommend all users to upgrade to Flink Kubernetes Operator 1.6.1.
